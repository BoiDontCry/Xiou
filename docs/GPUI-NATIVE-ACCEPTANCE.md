## 安全准备

- 使用独立 Windows 测试配置目录；隔离 LOCALAPPDATA、APPDATA、TEMP/TMP、
  FOXMAIL_INDEX_PATH、FOXMAIL_BACKUP_DIR，移除 FOXMAIL_IMAP_PASSWORD。
- 只使用虚构 `.invalid` 账号与本地测试 EML/SQLite，不复制真实凭据或邮件。
- 输入法防误发测试保持收件人为空，不填写可投递地址；不运行 smtp-send。
- 确认运行的是已核对哈希的候选版，而非桌面旧 release；交互验收时关闭
  FOXMAIL_AUTO_EXIT_MS，并只操作该测试进程。不为测试停止用户现有程序。
- 保存每项的 EXE 哈希、Windows/输入法版本、DPI、步骤、实际结果和截图/录像。
